# B 给 C 的可视化优化需求清单

**提出人**：B（易雨杰）
**日期**：2026 年 9 月 22 日
**对象**：C（戴燕岚，GraphPanel 模块）
**说明**：以下是当前集成测试中发现的可视化优化点，均在 GraphPanel 内修改，不涉及其他模块接口。

---

## 一、图例优化

### 当前问题
- 图例现在是 160×118 大小，字体 12f，在右上角占了不小一块地方
- 图例里有 4 项：普通节点、环路径、当前拓扑序、选中节点
- 其中"普通节点"就是默认状态，大部分时间看到的都是它，不需要特意说明
- "环路径"只有输入有环图的时候才会出现，平时看不到，放在图例里多余
- 整体间距比较大，显得松散

### 优化要求
1. 图例整体调小：宽度缩到 130 左右，高度缩到 95 左右，字体改成 10f
2. 去掉"普通节点"和"环路径"两项，只保留：
   - 当前拓扑序（颜色跟着实际选中的结果行变）
   - 选中节点
3. 行间距调紧凑一点，不要松散
4. 图例位置保持在右上角，但不要遮挡节点

---

## 二、节点加序号徽章

### 当前问题
- 现在点不同结果行，只有节点整体变颜色（绿→橙→蓝→紫→红）
- 但看不出顺序有什么差异，因为没有标每个节点排第几
- 5 色轮换只是换了个颜色，没有实际区分意义

### 优化要求
1. 在每个节点的右上角加一个小圆圈徽章
2. 徽章里标上这个节点在当前这条拓扑序里排第几（1、2、3……）
3. 徽章颜色和节点边框颜色保持一致
4. 效果示例：
   - 第 1 条结果：A 标 1，B 标 2，C 标 3……
   - 第 2 条结果：B 标 1，A 标 2，C 标 3……
5. 这样不同结果的顺序差异一眼就能看出来，颜色区分才有意义

---

## 三、边跟着拓扑序高亮

### 当前问题
- 现在点了某条拓扑序，只有节点变颜色，边还是灰色的
- 看不出完整的路径，只是节点变了色

### 优化要求
1. 属于当前拓扑序的边（from 和 to 都在 selectedOrder 里），边的颜色跟着变
2. 边的颜色和节点边框颜色一致
3. 边的粗细加粗一点（从 1.4f 改成 2.2f），突出路径
4. 这样点某条结果，这条拓扑序经过的节点和边都高亮，整个路径一目了然

---

## 四、放大缩小按钮位置调整

### 当前问题
- 现在放大、缩小、重置视图按钮在顶部工具栏，操作的时候要把鼠标移到顶部，不方便
- 图已经在中间了，按钮在工具栏很远

### 优化要求
1. 把放大、缩小、重置视图三个小按钮放到关系图窗口的右下角
2. 按钮做小一点，不要太大
3. 不用动 MainFrame 的工具栏，直接在 GraphPanel 右下角加就行
4. 滚轮缩放保留，不用改
5. 等你把右下角的按钮加好后，B 会把工具栏里原来的放大缩小按钮删掉，不用你动工具栏

---

## 五、左上角加"放大查看"按钮

### 当前问题
- 关系图在主页面显示太小了，节点和边都挤在一起
- 有些拓扑排序的图比较大，主窗口显示的时候会被遮挡一部分

### 优化要求
1. 在关系图窗口的左上角加一个"放大查看"按钮
2. 点击后弹出一个新窗口，把 GraphPanel 放进去，放大看
3. 新窗口可以独立缩放平移，不影响主窗口
4. 这样大图也能看清楚细节

---

## 六、点计算后关系图自动自适应

### 当前问题
- 点完计算后，图的位置和缩放还是上次的，有时候节点会被窗口边缘挡住
- 大图进来要手动缩放平移才能看全

### 优化要求
1. 点完计算、新图加载进来后，自动重新计算布局
2. 自动缩放和居中，让所有节点都完整显示在视图里
3. 不用用户手动调整
4. 注意：这个由 B 的 MainController 在 setGraph 之后调用 C 的 resetView() 就行，不用 C 改

---

3. 不用做悬浮缩略图，有放大查看窗口就够了
4. 改完在 dev-c 分支提交，B 这边会合并到 dev-b
