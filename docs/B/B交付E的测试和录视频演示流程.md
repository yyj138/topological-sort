B交付E的测试和录视频的演示流程

一、开头介绍

1. 打开命令行，输入 java -cp out ui.MainFrame 启动软件

2. 展示主界面：左侧输入区、中间关系图、右侧结果列表、底部状态栏

旁白：这是我们的拓扑排序应用软件，输入课程先修关系，自动绘制关系图并枚举所有可能的拓扑排序结果

二、载入图1数据

1. 点【载入文件】按钮

2. 选择 data/figure1.txt

3. 左侧文本区显示所有 <a,b> 格式的边

4. 右侧表格自动同步显示所有边

5. 中间关系图自动环形布局，所有节点蓝色

旁白：我们先载入任务书图1的课程先修关系数据，支持文本和表格两种编辑方式，关系图自动环形布局

三、计算拓扑排序

1. 点【计算】按钮

2. 状态栏显示：节点数、边数、无环、序列数、耗时

3. 右侧结果列表分页显示所有拓扑排序结果

4. 切换分页（上一页/下一页）

旁白：点击计算，算法自动枚举所有可能的拓扑排序，默认最多显示1000条，支持分页查看

四、高亮选中序列

1. 单击第1条结果 → 全图节点变绿色，每个节点右上角标序号徽章（1,2,3,4...）

2. 单击第2条结果 → 全图变橙色

3. 单击第3条结果 → 全图变紫色

4. 双击第1条结果 → 复制到剪贴板

旁白：单击任意结果，关系图会高亮显示这条拓扑序列，不同结果用不同颜色区分，节点上的序号表示该节点在序列中的位置，双击可复制

五、环检测演示

1. 左侧文本区清空，输入3条有环的边：

   <A,B>

   <B,C>

   <C,A>

2. 点【计算】

3. 弹窗提示「图中存在环，无法进行拓扑排序」

4. 关系图上环上的节点和边全部变红

5. 状态栏显示「含环」

旁白：如果输入有环的图，系统会自动检测并红色高亮显示环路径，无法进行拓扑排序

六、导出功能演示

1. 切回 data/figure1.txt，点计算

2. 点【导出结果】→ 保存为 txt 文件

3. 点【导出图片】→ 保存关系图为 PNG

旁白：支持导出排序结果为txt文件，也支持导出关系图为PNG图片

七、异常输入处理

1. 左侧输入 <A,>（不完整的边）

2. 点计算 → 弹窗提示「第1行：...」

旁白：系统有完善的异常处理，非法输入会给出明确的中文错误提示和行号定位
