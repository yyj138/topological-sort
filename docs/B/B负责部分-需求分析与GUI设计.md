## 一、需求分析

### 1.1 功能需求
本项目是基于图形界面的拓扑排序工具，核心功能需求如下：

| 需求项 | 描述 | 优先级 |
|--------|------|--------|
| 关系输入 | 支持文本粘贴、TXT文件导入、表格编辑三种输入方式 | 高 |
| 自动建图 | 解析 `<a,b>` 格式关系，自动去重、识别自环、错误行号提示 | 高 |
| 拓扑排序枚举 | 枚举所有合法拓扑排序结果，默认上限1000条 | 高 |
| 环检测 | 自动检测有向环并红色高亮显示环路径 | 高 |
| 可视化展示 | 分层/环形双布局，支持缩放、平移、节点拖动 | 高 |
| 结果联动 | 点击结果列表，图上同步高亮对应拓扑序，标注顺序序号 | 高 |
| 导出功能 | 支持TXT/CSV结果导出、PNG关系图导出 | 中 |
| 稳定保护 | 30秒超时、计算过程可取消，大图运算不卡死 | 中 |

### 1.2 非功能需求
- 跨平台：Windows/Linux/macOS 均可运行
- 零依赖：纯JDK标准库，无需额外安装第三方包
- 易用性：操作逻辑清晰，普通用户5分钟内可上手
- 性能：100节点以内图秒级响应，1000条结果内无卡顿

## 二、GUI 设计

### 2.1 整体布局
采用经典的三栏式Swing布局：
```
┌──────────────────────────────────────────┐
│  工具栏：打开/保存/计算/取消/导出/布局切换 │
├──────────┬───────────────┬───────────────┤
│ 输入面板  │   关系图画布   │  结果列表面板  │
│ (左栏)   │    (中栏)     │   (右栏)      │
│          │               │               │
├──────────┴───────────────┴───────────────┤
│              状态栏：节点数/边数/提示信息     │
└──────────────────────────────────────────┘
```

### 2.2 各组件说明

#### 主窗口（MainFrame）
- 标题：拓扑排序应用软件
- 默认尺寸：1200×800，可最大化
- 顶部工具栏：图标+文字按钮，统一蓝色主题样式

#### 输入面板（InputPanel）
- 多行文本输入框，支持粘贴关系数据
- 底部按钮：导入文件、清空、示例数据
- 自动校验输入格式，错误时弹窗提示行号

#### 结果面板（ResultPanel）
- 分页显示，每页20条结果
- 单击选中某条结果，图上同步高亮
- 双击复制当前结果到剪贴板
- 底部分页按钮：首页/上一页/下一页/末页/复制/清空

#### 关系图画布（GraphPanel，组员C负责）
- 分层/环形双布局，右上角切换
- 滚轮缩放、拖拽平移
- 右下角悬浮按钮：放大/缩小/重置/放大查看
- 节点颜色随结果序号轮换：绿/橙/紫/青/粉五色循环

#### 状态栏（StatusBar）
- 左侧显示：节点数、边数、结果总数
- 右侧显示：当前状态提示（计算中/完成/取消/环提示）

### 2.3 交互流程
1. 用户在左栏输入或导入关系数据
2. 点击"计算"按钮，后台线程开始解析、建图、枚举
3. 计算过程中可点击"取消"中断
4. 计算完成后，中栏显示关系图，右栏显示所有拓扑序结果
5. 用户点击右栏某条结果，中栏图同步高亮该拓扑序的节点路径和顺序
6. 用户可缩放、平移、切换布局查看大图
7. 可将结果导出为TXT/CSV，或将关系图导出为PNG
