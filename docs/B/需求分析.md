# GUI与控制模块需求分析

## 一、模块概述
GUI与控制模块是整个拓扑排序工具的交互入口，负责接收用户输入、调度后台计算任务，并将算法、可视化和文件IO模块的结果整合展示在统一窗口中。

## 二、功能需求
1. 提供图形化主窗口，三栏布局：左侧输入、中间画关系图、右侧显示结果
2. 支持点击"计算"按钮触发拓扑排序，计算在后台线程运行，不卡界面
3. 支持"取消计算"按钮中断枚举任务
4. 结果列表分页显示，每页20条，支持翻页
5. 点击结果列表某行，关系图同步高亮对应拓扑序，节点标注顺序序号
6. 支持导出结果为TXT/CSV，文件头写明结果是否完整和停止原因
7. 所有错误统一中文弹窗提示，带具体行号

## 三、非功能需求
- 界面响应流畅，千条结果分页渲染不卡顿
- 纯Java Swing实现，跨平台，无第三方依赖
- 所有耗时操作后台执行，UI线程始终响应
- 按钮和文字风格统一，无乱码
