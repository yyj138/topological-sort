## 二、类设计与实现

在可视化模块中，我设计了三个核心类，各司其职：

1. **GraphPanel**：继承自 `JPanel`，作为核心绘图组件。内部持有一个 `LayoutManager` 实例，负责管理图数据、高亮状态、视图缩放和平移，并重写 `paintComponent` 方法作为绘制入口。
2. **LayoutManager**：负责根据图结构计算节点坐标。采用策略模式，通过 `mode` 字段区分分层布局与环形布局。
3. **ImageExporter**：静态工具类，负责图片导出的目录选择、文件名生成和错误提示。

## 三、核心算法实现与验证

### 1. 分层布局算法
为了让关系图层次分明、减少边交叉，我实现了基于拓扑层的分层布局：
- **算层号**：使用 Kahn 算法的变体，入度为 0 的节点在第 0 层，逐层递推。若图中存在环，环上的节点统一放到最末层兜底，保证布局可读。
- **重心法排序**：同层节点取其所有前驱节点横坐标的平均值作为排序键，使得节点尽量靠近其前驱，显著减少边的交叉。
- **坐标分配**：纵坐标按层号均匀分布，横坐标根据节点实际宽度加上最小间距在画布宽度内均匀展开。

### 2. 环形布局算法
作为含环图或特殊场景的兜底方案，将所有节点均匀分布在圆周上。圆心为 `(w/2, h/2)`，半径为 `min(w, h)/2 - r - 40`，第 i 个节点的角度为 `2πi/n - π/2`。

**验证结果：** 使用图1数据分别应用两种布局，均可正确渲染，节点无重叠，分层清晰，环形布局节点分布均匀。算法复杂度在 O(n+m) 到 O(n²) 之间，完全满足本项目课程数据规模（n ≤ 100）的需求。
