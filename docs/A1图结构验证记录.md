## 关键方法与边界

| 方法或行为 | 实现说明 |
| --- | --- |
| `addVertex` | 去重但不覆盖已有节点及其关系，新增返回 true |
| `addEdge` | 先验证两个端点，再按起点、终点顺序补齐缺失节点；新增关系同时维护后继、前驱与边数 |
| `removeEdge` | 两端存在且有边时同步删除关系并减少边数；边不存在返回 false；任一端点不存在抛出 IllegalArgumentException；不删除节点 |
| 名称校验 | 共用同一校验函数；使用 String.strip() 去除首尾空白，保留内部空格并区分大小写；拒绝 null、空名称、`<`、`>`、`,`、`＜`、`＞` 及换行（CR、LF、NEL、Unicode 行／段分隔符） |
| 节点和后继查询 | 返回按录入顺序排列的不可修改快照；再次查询可获得最新数据，旧列表不会随图变化 |
| 度数与统计 | 入度取前驱集合大小，出度取后继集合大小；图中维护去重边数；自环计一条边并分别贡献一个入度、出度 |
| 未知节点与非法参数 | 抛出带原因的 IllegalArgumentException，拒绝操作时图保持不变；不输出界面提示 |
| 存储与模块边界 | LinkedHashMap 保存节点，LinkedHashSet 保存直接邻接关系；不保存独立全图边列表，不添加间接边，不依赖 Swing 或文件解析 |

图的空间规模为 O(V+E)。忽略名称长度且按哈希表平均复杂度计，单次节点／边增删和度数查询为 O(1)，读取节点列表为 O(V)，读取某节点的后继快照为 O(该节点出度)。Graph 是可变且非线程安全的结构，调用方应在后台计算期间保证输入稳定。
