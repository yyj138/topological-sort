## 接口调用与结果解释

```java
import algorithm.AllTopoSorts;
import algorithm.EnumerationResult;
import model.Graph;

Graph graph = new Graph();
graph.addEdge("A", "C");
graph.addEdge("B", "C");
EnumerationResult result = new AllTopoSorts().enumerate(graph, 1000, 0, () -> false);
// 两条结果：[A, B, C]、[B, A, C]；isComplete() 为 true。
```

`maxResults` 由调用方按约定默认传入 1000，0 表示不限数量；`timeoutMillis` 的单位是毫秒，0 表示不限时间。图和取消函数不得为 null，数量和时间不得为负数，否则抛出 IllegalArgumentException。`cancelled` 应快速返回且不修改图，其抛出的异常原样交给调用方处理，不伪装成正常结束。

| 停止原因 | 已生成结果与完整性 |
| --- | --- |
| `COMPLETED` | 已穷尽所有选择，`isComplete()` 为 true，生成数量可作为确切总数 |
| `LIMIT_REACHED` | 已达到输出数量限制，完整性为 false；非空图恰好达到实际总数时，可能尚未确认所有结果均已找出，因此仍保守标记未完整 |
| `CANCELLED` | 检测到取消请求后停止计算，保留此前已生成的完整序列，完整性为 false ；正在生成但尚未完成的序列不予保留。 |
| `TIMEOUT` | 检测到超时后停止计算，保留此前已生成的完整序列，完整性为 false ；正在生成但尚未完成的序列不予保留 |
| `CYCLE` | 在展开枚举前已确认含环，结果数量为 0，完整性为 false |

空图正常完成时返回 `[[]]`，已生成数量为 1，停止原因是 COMPLETED；即使上限为 1，也已能直接证明这是唯一结果。入口已请求取消或已经耗尽时间时，会先报告取消或超时，而不是继续为判环或空图特例做计算。同一次检查先看取消、再看超时；数量上限在保存完整序列后检查，不额外生成一条结果来证明还有更多。

外层结果列表和每条序列都不可修改，构造时复制必要的可变列表，不共享回溯中的工作数组。每次调用都有独立的入度、使用标记、候选下标和输出列表，正常完成、限量、中断或回调异常都不会改变原图。按当前图的录入顺序稳定尝试候选节点，算法不会把结果排序规则误作拓扑合法性的判断标准。

## 实现流程与复杂度

首先把节点名称映射到局部下标，复制直接后继和初始入度，再在副本上用 Kahn 的处理计数判环。复制和判环期间也检查取消与超时，因此没有直接调用缺少中断参数的 A2 方法；仍使用相同的 Kahn 原理，并用既有模块回归测试确认一致性。检测到环时直接返回 CYCLE，不因孤立节点很多而先进入排列搜索。

无环时使用显式回溯：每层记录下一次要尝试的节点下标，选择尚未使用且当前入度为 0 的节点，将其放入路径并减少后继入度。路径包含全部节点时，复制保存一条结果；继续搜索前撤销本层选择并恢复后继入度，某层没有其他候选时回退到上一层。使用数组记录深度和候选位置，不依赖 Java 递归调用栈。

预处理为 O(V+E)，枚举耗时还取决于实际访问的搜索状态与输出条数，不能宣称整体为 O(V+E)。初版在每个搜索状态扫描至多 V 个候选；忽略名称长度、按哈希表平均复杂度计，若访问 P 个搜索状态并输出 R 条序列，可用 O(V+E+PV+RV) 表示上界。空间为 O(V+E+RV)，其中 RV 是保存返回序列所需的空间；不限数量不会消除结果规模带来的内存开销。

运行时限使用单调时钟 System.nanoTime，包含图复制、判环和搜索，极大毫秒参数采用饱和转换避免溢出。停止是协作式检查，不能中断正在执行的用户回调、集合复制或结果封装，因此毫秒参数不是硬实时截止保证。测试通过同包可见的时钟注入入口验证超时，正式公开调用仍使用无参构造器及契约中的 enumerate 方法。

## 复现命令

在仓库根目录使用 JDK 21 和 UTF-8 执行以下 PowerShell 命令。编译开启全部警告并将警告视为错误，失败时停止；编译产物保存在既有忽略目录 `out/a3`。图 1 的输出文件由自测程序生成，当前复现命令将新结果写入 `out/a3/all_results.txt`，其中耗时随本次运行变化，不覆盖历史交付文件 `docs/验证/all_results.txt`。

```powershell
$a3Sources = @(
    'src/model/Vertex.java', 'src/model/Edge.java', 'src/model/Graph.java',
    'src/algorithm/TopoResult.java', 'src/algorithm/TopologicalSolver.java',
    'src/algorithm/CycleDetector.java', 'src/algorithm/StopReason.java',
    'src/algorithm/EnumerationResult.java', 'src/algorithm/AllTopoSorts.java',
    'test/GraphSelfTest.java', 'test/TopologicalSolverSelfTest.java',
    'test/CycleDetectorSelfTest.java', 'test/algorithm/AllTopoSortsSelfTest.java'
)
javac -encoding UTF-8 --release 21 -Xlint:all -Werror -d out/a3 @a3Sources
if ($LASTEXITCODE -ne 0) { throw 'A3 编译失败' }
java -cp out/a3 algorithm.AllTopoSortsSelfTest data/figure1.txt out/a3/all_results.txt
if ($LASTEXITCODE -ne 0) { throw 'A3 自测失败' }
java -cp out/a3 GraphSelfTest
if ($LASTEXITCODE -ne 0) { throw 'A1 回归失败' }
java -cp out/a3 TopologicalSolverSelfTest data/figure1.txt
if ($LASTEXITCODE -ne 0) { throw 'A2 回归失败' }
java -cp out/a3 CycleDetectorSelfTest
if ($LASTEXITCODE -ne 0) { throw 'A4 回归失败' }
```

本次实际使用 `D:\jdk21\bin\javac.exe` 和 `D:\jdk21\bin\java.exe`，编译无警告，全部测试进程退出码为 0。自测类位于 algorithm 包，是为了访问同包测试时钟入口，因此运行类名带 `algorithm.` 前缀。不传两个文件参数时，仅执行 24 组基础自测并明确提示图 1 未运行。
