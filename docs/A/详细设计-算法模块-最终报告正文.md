# 3.1 算法模块

算法模块以有向图表示课程之间的先修关系，提供单个拓扑序列求解、多种拓扑序列枚举和环路径定位功能。图数据由 `model` 包维护，核心计算由 `algorithm` 包完成。各算法使用局部入度、访问标记和搜索路径进行运算，不修改原图，保证同一份关系数据能够重复用于排序和绘图。

## 3.1.1 图数据结构设计

系统采用邻接表思想存储有向图，边 u→v 表示课程 u 必须先于课程 v。图模型由 `Vertex`、`Edge` 和 `Graph` 三个类组成，分别描述节点、有向边值对象和整张图的管理行为。合法拓扑序列应包含全部节点且各出现一次，并保证每条边的起点位于终点之前。

`Vertex` 保存节点名称、直接前驱集合和直接后继集合，入度和出度分别由两个集合的大小得到。前驱和后继采用 `LinkedHashSet`，既避免重复关系造成度数错误，又保持关系录入顺序。`Edge` 保存不可变的起点与终点名称，以两个端点及方向判断相等性，构造边对象本身不会改变图中的关系。

`Graph` 使用 `LinkedHashMap<String, Vertex>` 管理节点，通过节点内部的前驱、后继集合保存实际关系，并单独记录边数。添加边时自动补齐缺失节点，同步维护两端邻接关系；重复边不重复计数，删除边后保留节点，孤立节点也可以独立添加。图允许自环和一般环，由算法判断能否排序；节点和后继查询返回不可修改的列表快照，计算过程另建状态副本，图存储空间为 O(n+m)，其中 n 为节点数，m 为边数。

## 3.1.2 Kahn 拓扑排序设计

`TopologicalSolver` 使用 Kahn 算法求出一种合法拓扑序列，其入口为 `kahnSort(Graph graph)`。算法首先复制各节点入度，将所有零入度节点按录入顺序放入先进先出队列。随后不断取出队首节点加入结果，并减少其直接后继的局部入度，后继入度降为零时再加入队列。

```text
复制各节点入度到 degree，将零入度节点加入队列 Q
order ← 空序列
while Q 非空:
    u ← 队首出队，将 u 加入 order
    for v in u 的直接后继:
        degree[v] ← degree[v] - 1
        若 degree[v] = 0，将 v 加入 Q
若 order 的长度等于节点总数，返回完整序列及无环标记
否则返回空序列及含环标记
```

每次出队的节点都没有尚未处理的前驱，因此追加它不会破坏已有依赖关系。若全部节点均被处理，得到的顺序就是合法拓扑序列；若仍有节点未处理但队列已空，则剩余节点间存在循环依赖。结果使用 `TopoResult` 封装，含环时丢弃局部前缀并返回空序列，空图则返回空序列且标记为无环。

例如，对于 A→C、B→C，初始队列为 A、B，处理 A 后 C 的入度从 2 降为 1，处理 B 后降为 0，最终得到 `[A,B,C]`。每个节点最多入队和出队各一次，每条边只触发一次入度更新，因此时间复杂度为 O(n+m)，辅助空间复杂度为 O(n)。同一录入顺序下结果稳定，但算法只给出一种合法顺序，不保证字典序最小，也不据此判断答案是否唯一。

## 3.1.3 多种拓扑序列枚举设计

`AllTopoSorts` 采用深度优先搜索与回溯思想，将 Kahn 算法中的一次零入度选择扩展为逐一尝试所有可选节点。预处理将节点名称映射为整数下标，复制邻接数组和入度，并先通过带中断检查的 Kahn 过程判环。含环时直接结束；无环时，每层选择一个尚未使用且剩余入度为零的节点，搜索其后续排列，再恢复状态以尝试其他分支。

实现使用显式数组管理搜索深度，不依赖 Java 递归调用栈。`used` 标记当前路径中已选节点，`order` 保存排列，`inDegrees` 保存剩余入度，`nextCandidate` 记录每层下次扫描的位置。选择节点时标记使用并减少后继入度，回退时清除标记并恢复后继入度；路径包含全部节点后，复制保存一条完整序列。

```text
复制图数据并判环，初始化局部搜索状态
从深度 0 开始搜索:
    检查取消和超时，必要时返回已有完整序列
    若路径已包含全部节点:
        复制保存该序列，达到数量上限则结束
        回退一层并撤销该层选择
    否则从当前层记录的位置继续扫描候选节点:
        找到未使用的零入度节点，则选择它并进入下一层
        没有剩余候选，则回退并恢复父层选择前的状态
全部分支穷尽后，返回完整结果集合
```

以 A→C、B→C 为例，第一层可选择 A 或 B，两条分支分别生成 `[A,B,C]` 与 `[B,A,C]`。每层仅选择未使用的零入度节点，保证输出合法且节点不重复；任意合法序列的下一个节点都必定是相应状态下的可选节点，因此穷尽搜索能够覆盖所有合法序列。不同结果对应不同的选择路径，回退后继续扫描尚未尝试的候选，可避免重复生成相同排列。

枚举入口接收数量上限、毫秒时限和取消函数，数量或时限参数为 0 时表示关闭对应限制。结果通过 `EnumerationResult` 返回序列集合、已生成数量、完整性及停止原因，只有搜索穷尽时才标记为 `COMPLETED`；达到上限、取消、超时或含环分别对应 `LIMIT_REACHED`、`CANCELLED`、`TIMEOUT` 和 `CYCLE`。取消或超时保留此前生成的完整序列，达到上限则将结果标记为未完整；即使上限恰好等于实际总数，也要在搜索穷尽后才能确认完整性。

预处理时间为 O(n+m)，设实际访问的搜索状态数为 P、输出序列数为 R，当前实现逐层扫描候选的时间上界为 O(n+m+Pn+Rn)，空间复杂度为 O(n+m+Rn)。其中 O(Rn) 是保存结果的开销，无边图具有 n! 种合法序列，因此全枚举的开销主要受约束结构和结果规模影响。显式回溯避免深层递归的调用栈问题，数量限制与协作式取消、超时检查则控制实际搜索规模，但不消除结果数量的组合增长。

## 3.1.4 环检测与路径定位设计

`CycleDetector` 的入口为 `findCycle(Graph graph)`，先调用 Kahn 算法判断图是否含环，无环时返回空列表。确认含环后，采用三色深度优先搜索定位具体环路径：白色表示未访问，灰色表示位于当前搜索路径，黑色表示该节点的后继已全部处理。实现使用显式迭代器栈保存搜索进度，并使用 `path` 记录当前路径，逐个检查未访问的根节点以覆盖不连通分量。

```text
若 Kahn 判定无环，返回空列表
从每个未访问节点开始深度优先搜索:
    将节点标灰、加入 path，并压入其后继迭代器
    检查下一后继 v:
        v 为白色，则进入 v 继续搜索
        v 为灰色，则截取 path 从 v 开始的后缀并追加 v，返回环
        v 为黑色，则继续检查其他后继
    当前节点无剩余后继时，弹栈、移出 path 并标黑
```

指向灰色节点的边与当前路径的一段共同构成有向环，而指向黑色节点仅表示到达已经完成的分支。若搜索路径为 X→A→B→C，发现 C→A 时返回 `[A,B,C,A]`，排除进入环前的 X；自环则返回 `[A,A]`。返回路径首尾相同且相邻节点间均存在真实有向边，可直接用于循环依赖提示和环高亮，算法找到第一条环后结束，不枚举全部环或寻找最短环。

Kahn 预判和深度优先搜索均为 O(n+m)，首次提取环路径需要 O(n)，整体时间复杂度仍为 O(n+m)。颜色表和当前路径需要 O(n) 空间，显式栈还保存节点后继快照，因此辅助空间上界为 O(n+m)。搜索状态均在本次调用中独立创建，计算期间保持输入图稳定，使排序、环定位和后续绘图共享一致的原始关系。
