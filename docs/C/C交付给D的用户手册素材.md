## 一、图片导出说明

### 1. “导出图片”按钮功能说明

- **位置**：顶部工具栏中的【导出图片】按钮。
- **功能**：将当前关系图视图中的内容导出为一张 PNG 图片。
- **前提条件**：需要先点击【计算】并成功绘制出关系图，否则会弹出提示“没有可导出的关系图，请先计算”。
- **导出内容**：
  - 关系图的完整内容（无论当前画布是否缩放或平移，都会自动导出完整关系图，而非仅导出当前视口）。
  - 包含节点、有向边、箭头、自环、图例。
  - 包含环路径高亮、拓扑序高亮、选中节点高亮等当前视图状态。
- **交互流程**：
  1. 点击【导出图片】。
  2. 弹出目录选择框，用户选择保存目录。
  3. 程序自动生成带时间戳的文件名并保存。
  4. 弹出“导出成功”提示，显示文件完整路径。
  5. 如果用户取消选择，则静默返回，不生成文件。

### 2. PNG 文件命名规则

- **命名格式**：`graph_年月日_时分秒.png`。
- **示例**：`graph_20260923_153045.png`。
- **同秒重复处理**：如果在同一秒内多次导出，程序会自动加序号避免覆盖：
  - 第 1 次：`graph_20260923_153045.png`
  - 第 2 次：`graph_20260923_153045_1.png`
  - 第 3 次：`graph_20260923_153045_2.png`

### 3. 中文字体处理

- 导出时画布字体统一设置为 **“Microsoft YaHei”（微软雅黑）**，保证中文节点名（如课程名）在 PNG 中不乱码。
- 如果导出的图片中仍然出现中文乱码，通常是操作系统未安装微软雅黑字体所致，可联系 C 排查，或尝试在系统中安装该字体。
- 节点宽度根据文本动态估算：中文字符按 14 像素、西文字符按 8 像素累加，确保课程名不溢出。

## 二、布局切换说明

### 1. 两种布局的区别

| 布局模式 | 适用场景 | 视觉特点 |
| :--- | :--- | :--- |
| **分层布局** | 无环图、课程先修关系等有明确层级结构的图 | 按拓扑层从上到下排列，入度为零的节点在第 0 层，逐层递推；同层节点横向均匀分布，采用重心法减少边交叉，层次分明 |
| **环形布局** | 含环图、特殊场景兜底方案 | 所有节点均匀分布在一个圆周上，圆心在画布中心，半径根据画布短边动态计算；适合展示节点之间的环形依赖关系 |

### 2. 切换方式

- **工具栏按钮**：顶部工具栏提供【分层布局】和【环形布局】两个按钮，点击即可切换。
- **切换效果**：切换后关系图会自动重新排列，无需手动调整。
- **不闪烁、无错乱**：切换过程中画布平滑重绘，节点不会残留上一布局的位置。

### 3. 适用场景补充说明

- 当用户输入含环的数据时，程序会弹窗提示“图中存在环”，并红色高亮环路径。此时无论切换哪种布局，环路径高亮都不会消失。
- 如果用户手动拖动过节点位置，切换布局后节点会按照新布局重新排列，不再保留手动调整的位置。
- 如果切换后觉得视图不对，可以点击右下角的【重置】按钮恢复默认缩放和平移位置。

## 三、常见问题解答（C 补充）

| 常见问题 | 原因 | 解决方法 |
| :--- | :--- | :--- |
| 导出 PNG 后图片是空白的，只剩下图例 | 早期版本在平移或缩放画布后直接导出，导致节点被裁剪 | 已修复：现在导出会忽略当前缩放和平移，按节点包围盒 1:1 完整导出完整关系图。如仍遇到，请联系 C |
| 导出 PNG 后右上角图例遮挡了节点或自环 | 早期版本图例固定画在右上角，与右上角节点重叠 | 已修复：现在导出时会在图片顶部为图例预留独立空间，节点整体向下平移，彻底避免遮挡。如仍遇到，请联系 C |
| 导出 PNG 中文乱码 | 未正确设置中文字体 | C 已在导出时设置微软雅黑字体；如仍乱码，可能是系统缺少该字体，请安装后重试 |
| 布局切换后节点重叠或错乱 | 用户手动拖动过节点，或画布尺寸变化后未重新布局 | 点击右下角【重置】按钮恢复默认视图；如仍异常，请联系 C |
| 放大查看窗口不显示环形布局 | 早期版本弹出窗口默认使用分层布局，未同步主窗口布局 | 已修复：现在弹出窗口会复制主窗口的布局模式，无论主窗口是分层还是环形，弹窗都会一致显示。如仍遇到，请联系 C |
| 滚轮无法缩放 | 集成后滚轮事件被外层容器拦截 | 已改为工具栏按钮缩放；右下角提供 `+` / `-` / `重置` 三个按钮，滚轮缩放仍保留，如滚轮失效可用按钮替代 |
| 导出的图片尺寸与画布不一致 | 导出按完整关系图包围盒计算，不套用当前缩放 | 这是预期行为：导出的是完整图，与当前视图缩放无关 |
