## 二、本次修改内容

针对之前检查中发现的导出问题，C 在 `GraphPanel.java` 中做了两处修复：

| 修改位置 | 修改内容 |
|---|---|
| `GraphPanel.exportPNG()` | 修复「平移/缩放画布后导出图片空白/残缺」的问题，改为忽略当前视图变换，遍历所有节点计算包围盒，按 1:1 完整导出关系图 |
| `GraphPanel.exportPNG()` | 修复「右上角图例遮挡节点和自环」的问题，在计算图片高度时为图例预留独立顶部空间，并将节点整体向下平移，彻底避免图例与节点重叠 |

另外，关于缩放交互，C 原本实现的是鼠标滚轮缩放，单测正常；集成到 B 的 UI 布局后，滚轮事件被外层容器拦截，导致滚轮缩放失效。经与 B 协商，B 已在工具栏增加「放大」「缩小」按钮作为替代入口，经测试按钮缩放正常。

## 五、C 的实现说明（供参考）

C 的 `GraphPanel` 负责：
- 布局：通过 `LayoutManager` 计算分层/环形坐标；
- 绘制：绘制节点、有向边、箭头、自环，并支持环路径红色高亮、拓扑序列 5 色轮换、选中节点黄色高亮；
- 交互：滚轮缩放（单测正常，集成后由工具栏按钮替代）、拖拽平移、拖动节点、双击查看信息；
- 导出：`exportPNG` 忽略视图变换，计算节点包围盒并预留图例空间，1:1 导出完整关系图。

`ImageExporter` 负责弹出目录选择框，自动生成带时间戳的文件名，并处理导出失败的中文提示。
