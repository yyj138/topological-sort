# A—C 可视化接口与 PNG 复核记录

整理日期：2026 年 9 月 22 日。本文依据 A 留存的 B/C 接口比对及两轮 PNG 专项验证材料，记录 A 在模块衔接、问题定位和修复复测中的实际工作。GraphPanel、LayoutManager 和 ImageExporter 的实现及修复由 C 完成，本文不将 C 的代码工作计入 A，也不将组件级验证扩大为完整 GUI 验收。

## 接口衔接与职责确认

B/C 提供过编码期新增调用清单，涉及拓扑序高亮、单节点高亮、布局切换、视图复位、缩放比例和图片导出入口。A 将清单与双方代码进行比对，再维护公共接口契约；留存快照标识为 B `a355db1d076a2425a666f9def702bd0004a93e7b`、C `a04b212d156302f9a297148254f907430856fe80`。当前 [接口契约](../接口契约.md) 保留原三个 GraphPanel 方法，补充六个公开方法、两个布局模式常量和两个 ImageExporter 入口，节点尺寸及宽度估算等内部绘图细节仍由 C 的设计材料维护。

A 特别核对了“完整关系图导出”的含义：缩放、平移和节点拖动后，导出仍应覆盖全部节点与边。新增工具类不能把该要求改成截图当前窗口，签名兼容也不能单独证明行为满足约定。后续专项检查围绕这一接口行为展开，A 的算法和 Graph 无需为了掩盖绘图问题改变接口。
