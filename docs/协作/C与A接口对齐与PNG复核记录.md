## 一、接口对齐范围

C 的 GraphPanel 通过 `setGraph(Graph)` 从 A 的 model 包获取图数据，
读取 A 提供的以下方法：

| A 提供的方法 | C 的用途 |
| :--- | :--- |
| `graph.getVertexNames()` | 获取所有顶点，遍历绘制 |
| `graph.getSuccessors(name)` | 获取某节点的后继，用于画有向边 |
| `graph.getInDegree(name)` | 双击节点时显示入度 |
| `graph.getOutDegree(name)` | 双击节点时显示出度 |
| `graph.getVertexCount()` | 状态栏显示节点数 |
| `graph.getEdgeCount()` | 状态栏显示边数 |

以上接口在 9.17 接口冻结会上确认，编码期未再变更。

## 二、PNG 导出复核记录

### 1. 首次复核（A 提出）
A 在测试中发现：
- 平移或缩放画布后导出 PNG，图片会出现空白或残缺，节点被裁剪；
- 原因：C 的 `exportPNG` 套用了当前的 `scale` 和 `offsetX/offsetY`。

### 2. C 的修复
C 修改 `GraphPanel.exportPNG(File)`：
- 忽略当前视图的缩放和平移；
- 遍历所有节点计算包围盒，按 1:1 完整绘制；
- 保证无论用户如何缩放平移，导出始终是完整关系图。

### 3. 二次复核（A 再次提出）
A 复测发现：
- 导出完整图后，右上角图例会遮挡正好位于右上角的节点或自环。

### 4. C 的二次修复
C 修改 `exportPNG`：
- 计算图片高度时预留图例空间（`LEGEND_HEIGHT + LEGEND_GAP`）；
- 将节点整体向下平移，彻底避免图例与节点重叠。

### 5. A 最终复核结论
A 已在 dev-b 分支复核通过：
- 平移后导出，节点完整；
- 缩放后导出，图片 1:1 完整；
- 图例不再遮挡节点和自环；
- 中文节点名显示正常，无乱码。
