## 一、界面各区域说明

| 序号 | 区域 | 位置 | 功能说明 |
|---|---|---|---|
| 1 | 顶部工具栏 | 窗口最上方 | 从左到右依次为：打开文件、清空输入、计算、取消计算、导出结果、导出图片、布局切换（分层/环形） |
| 2 | 输入面板 | 左栏 | 多行文本编辑区，直接粘贴 `<先修,后继>` 格式的关系数据；下方有"导入文件""清空""示例数据"按钮 |
| 3 | 关系图画布 | 中栏 | 显示课程先修关系图，节点是课程，箭头是先修关系；左下角显示缩放比例，右下角有悬浮缩放按钮 |
| 4 | 结果列表面板 | 右栏 | 分页显示所有拓扑排序结果，每页20条；顶部显示总结果数，底部有分页和复制按钮 |
| 5 | 状态栏 | 窗口最下方 | 左侧显示节点数、边数、结果总数；右侧显示当前状态提示 |

## 二、完整操作流程

1. 打开软件，在左栏文本框输入关系数据，或点击"导入文件"选择 `.txt` 数据文件
2. 点击工具栏"计算"按钮，系统后台开始解析数据、构建图、枚举拓扑序
3. 计算过程中可随时点击"取消计算"中断，已生成结果保留
4. 计算完成后，中栏显示关系图，右栏显示所有拓扑排序结果列表
5. 点击右栏某条结果，中栏图会高亮该排序的节点路径，节点上标注顺序序号
6. 可使用鼠标滚轮缩放、拖拽平移查看大图，点右下角"重置"按钮恢复默认视图
7. 点击"导出结果"可将排序结果保存为 TXT 或 CSV 文件
8. 点击"导出图片"可将当前关系图保存为 PNG 文件
9. 可点击右上角切换分层/环形两种布局查看图

## 三、界面交互说明

| 交互操作 | 效果说明 |
|---|---|
| 鼠标滚轮滚动 | 在关系图画布上滚动滚轮，以鼠标位置为中心缩放图 |
| 左键拖拽空白处 | 平移整个关系图视图 |
| 左键按住节点拖动 | 手动调整节点位置，松开后固定 |
| 左键单击节点 | 高亮选中该节点（黄色背景），再点一次取消选中 |
| 单击结果列表某行 | 图上同步高亮该拓扑序路径，节点颜色随结果序号轮换（绿/橙/紫/青/粉） |
| 双击结果列表某行 | 复制该条排序结果到剪贴板 |
| 左上角 `<>` 按钮 | 弹出独立放大查看窗口，显示大图，窗口布局跟随主窗口 |
| 右下角 `+` 按钮 | 放大图 |
| 右下角 `-` 按钮 | 缩小图 |
| 右下角"重置"按钮 | 恢复默认缩放和平移位置 |

## 五、常见问题（B补充）

| 问题描述 | 原因 | 解决方法 |
|---|---|---|
| 点击计算后界面卡住 | 计算在后台线程，界面不会卡 | 等待计算完成，或点"取消计算" |
| 点结果图上颜色没变化 | 大部分节点顺序固定，只有并行节点顺序不同 | 看节点上的序号徽章变化，或看节点颜色变化 |
| 导出的CSV用Excel打开乱码 | 编码问题 | 文件带UTF-8 BOM，用Excel打开即可 |
| 节点拖乱了找不回来 | 手动拖动过节点 | 点右下角"重置"按钮恢复默认布局 |
