## 1、标准正式格式

每行一条先修-后修关系，使用**英文半角符号**：

```
<先修课程,后修课程>
```

示例：

```
<MA 140,MA 141>
<MA 141,CS 150>
<CS 150,CS 155>
```

规则：

- 每行最多一条关系；
- 空行会被解析器跳过；
- 以 `#` 开头的行是注释行，会被跳过；
- 正式保存采用英文半角 `<a,b>` 格式。

---

## 2、节点名称规则

1. 名称允许中文、字母、数字、内部空格，例如 `MA 141`、`CS 225`、`高等数学`；
2. 名称区分大小写，`A` 和 `a` 是两个不同的节点；
3. 名称去除首尾空白后作为唯一标识；
4. 名称不允许包含以下字符：
   - 半角尖括号 `<`、`>`；
   - 半角逗号 `,`；
   - 换行符 `\n`、`\r`；
   - Unicode 行分隔符 `\u0085`（NEL）、`\u2028`（LINE SEPARATOR）、`\u2029`（PARAGRAPH SEPARATOR）；
5. 空名称非法，如 `<>`、`<,>`、`<A,>` 会被拒绝；
6. 节点名称的规则与 A 模块的 `model.Vertex.normalizeName` 保持一致。

---

## 3、兼容输入

解析阶段会静默做以下转换，不报错：

| 兼容输入 | 转换后 |
|---|---|
| 全角尖括号 `＜` `＞` | 半角 `<` `>` |
| 全角逗号 `，` | 半角 `,` |
| 行首尾空白字符 | 去除 |

说明：

- 《接口契约》只明确要求兼容**全角尖括号**；
- **全角逗号**是 D 的扩展兼容，接受范围以本文档为准；
- 解析阶段静默转换，用户不会看到因全角输入产生的报错。

---

## 4、文件保存规则

1. 保存到磁盘时，统一转为**英文半角标准格式**；
2. 保存文件换行统一使用 `\n`（LF）；
3. 解析器读取文件兼容三类换行：`\r\n`（Windows）、`\r`（老 Mac）、`\n`（Unix/Linux）；
4. 保存时全角尖括号、全角逗号统一转半角，规则与 `DataParser`、`InputValidator` 保持一致；
5. 保存文件编码统一使用 UTF-8。

---

## 5、特殊业务规则

### 5.1 自环

- 自环 `<A,A>` 作为合法边保留入图；
- 自环的环路路径识别由 A 模块的 `CycleDetector` 完成；
- 单条自环**不产生警告**；
- 重复自环 `<A,A>\n<A,A>` 的第二次出现作为重复边，产生警告“重复的关系 <A,A>，已忽略”。

### 5.2 重复边

- 重复边会被自动去重，图中只保留一条；
- 重复边产生警告，消息格式为：`重复的关系 <a,b>，已忽略`；
- 重复边不重复计入入度；
- `DataParser` 通过 `Graph.addEdge` 返回 `false` 识别重复；
- `InputValidator` 通过 `seenEdges` 集合识别重复；
- 两者对外行为、警告消息完全一致。

### 5.3 空数据

- 输入为空、或只有空行和注释行时，`InputValidator.validate(null)` 返回 `isValid=true`、错误数 0；
- `DataParser.parse(null)` 返回空图、无错误；
- **空数据的业务提示弹窗由上层 UI 模块（B）完成**，解析器/校验器不报错；
- InputValidator 仅执行语法格式校验，不负责业务提示。

### 5.4 孤立节点

- 关系对语法 `<a,b>` 只表示边，不能表达孤立节点；
- 孤立节点由 `Graph.addVertex` 单独保存；
- 当前输入语法无法通过文本表达孤立节点。

## 6、错误消息与行号

解析失败会返回结构化的 `ParseIssue`，包含：

- 从 1 开始的行号；
- 中文原因描述。

错误消息示例：

| 场景 | 错误消息 |
|---|---|
| 缺少左括号 | 格式错误：缺少左括号 '<' |
| 缺少右括号 | 格式错误：缺少右括号 '>' |
| 尖括号顺序错误 | 格式错误：尖括号顺序错误 |
| 括号内为空 | 格式错误：括号内为空 |
| 缺少逗号 | 格式错误：缺少逗号分隔符 |
| 起点名称为空 | 格式错误：起点名称为空 |
| 终点名称为空 | 格式错误：终点名称为空 |
| 名称含非法字符 | 起点/终点名称包含非法字符：XXX |
| 重复边 | 重复的关系 <a,b>，已忽略 |

完整的场景清单见 `docs/异常与边界场景清单.md`。
